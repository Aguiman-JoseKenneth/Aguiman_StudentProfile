# Activity 7 - Authentication & CRUD Functionality



An Apache Cordova mobile application integrated with a PHP/MySQL backend for user authentication (Login/Register) and Student Profile CRUD operations.



## 🚀 Backend & Database Setup Instructions



To run this application successfully, you must set up the local backend server (XAMPP):



**Start Local Server:**
   - Open **XAMPP Control Panel**.

   - Start **Apache** and **MySQL** services.



2. **Import MySQL Database:**

   - Open phpMyAdmin (`http://localhost/phpmyadmin/`) or MySQL Workbench.

   - Create a database named `student_db` (or your project's database name).

   - Import the provided SQL dump file located in the project repository.



3. **Backend API Endpoints:**

   - Place your PHP backend scripts in your XAMPP directory: `C:\xampp\htdocs\StudentProfile\` (or your corresponding folder).

   - Test backend availability via browser: `http://localhost/StudentProfile/`

---

## 📱 Android Emulator Connectivity



**API Base URL:** `http://10.0.2.2/StudentProfile/`
